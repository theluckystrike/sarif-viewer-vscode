# Open a SARIF log

Open any `.sarif` or `.sarif.json` file. Results are grouped by rule, worst level first.

- Click a result to open the file at its line, with the region highlighted.
- Use the level buttons, the Baseline and Suppressed menus and the filter box to narrow the list.
- The details pane shows the rule help, CWE tags, security severity, related locations and the code flow.
